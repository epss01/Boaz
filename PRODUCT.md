# Boaz

## Platform
Local web dashboard on Windows, controlling one BlueStacks 5 instance in future milestones.

## Stack
User approved Python 3.11, uv, Airtest, NiceGUI, and pytest.

## Users and purpose
A Clash of Clans player configuring repetitive Home Village farming. The first delivery runs a deterministic simulation and read-only emulator preview; it does not automate gameplay.

## Confirmed constraints
One account, English game UI, named JSON presets, one calibrated landscape resolution. No gem spending, remote access, database, or plugin system. Wall upgrades use user-marked targets and default off. Current simulation and future capabilities must be visibly distinct.

## Success
The dashboard starts without an emulator. Settings persist, controls work, simulation never sends input, and a connected emulator can supply screenshots. The approved implementation plan is the product brief.
